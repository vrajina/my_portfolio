# Global Project Context & Constraints (Глобальные правила проекта)

> [!IMPORTANT]
> **ИНСТРУКЦИЯ ДЛЯ ВСЕХ ИИ-АГЕНТОВ:** 
> Этот файл содержит фундаментальные правила проекта. Вы обязаны строго следовать этим правилам при написании кода, проектировании архитектуры и создании дизайна.

## 1. Технический Стек (Technical Stack)
- **Основной Фреймворк:** Astro (Static Site Generator). Выбран за счет нулевого JS в рантайме по умолчанию и компонентного подхода.
- **Стилизация:** Vanilla CSS (чистый CSS) с активным использованием CSS Variables и современных фич (Grid, Flexbox). **ЗАПРЕЩАЕТСЯ** использовать Tailwind CSS или другие утилитарные фреймворки (если нет прямого указания Заказчика).
- **Скрипты:** Vanilla JavaScript (ES6+) внутри компонентов. Использование TypeScript приветствуется для базовой типизации данных.
- **Пакетный менеджер:** npm.

## 2. Архитектурные Принципы (Architecture & Performance)
- **Island Architecture:** Использовать клиентский JavaScript (Astro Islands с директивами `client:load`, `client:visible` и т.д.) только для интерактивных элементов (анимации, формы). Основной контент рендерится статически.
- **Производительность:** Целевой показатель Google Lighthouse: **95-100 баллов** по всем метрикам.
- **Изоляция:** Стили инкапсулируются на уровне `.astro` компонентов, чтобы избежать глобальных конфликтов.

## 3. Языковая Политика (Language Policy)
- **Пользовательский интерфейс (UI):** Русский (Russian).
- **Исходный код (переменные, функции, классы):** Строго Английский (English).
- **Сообщения коммитов и комментарии в коде:** Английский (English).
- **Проектная документация (ТЗ, архитектура, артефакты):** Русский (Russian) для удобства взаимодействия с Заказчиком.

## 4. Дизайн и Эстетика (Design Guidelines)
- Проект должен выглядеть "премиально" и современно.
- Использовать качественную типографику (шрифты Google Fonts: Inter, Roboto, Outfit или аналоги).
- Обязательно наличие микро-анимаций (hover эффекты, плавные появления при скролле) для создания "живого" интерфейса.
- Поддержка темной темы (Dark Mode) — как минимум на уровне архитектуры CSS.
- **Типографика текстов:** Все тексты на сайте ОБЯЗАТЕЛЬНО прогоняются через типографическую обработку: правильные кавычки («ёлочки»), длинное тире (—), неразрывные пробелы перед предлогами/союзами, буква «ё».
- **Регистр заголовков:** В заголовках НЕ используем ALL CAPS. Заглавной делаем только первую букву заголовка (Sentence case).

## 5. Мульти-Агентный Процесс (Workflow)
Процесс идет строго по цепочке: `Business Analyst` -> `System Architect` -> `UI/UX Designer` -> `Developer` -> `QA` -> `DevOps`. Никаких прыжков через этапы без согласования.
